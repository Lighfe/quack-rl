# Ruleset v1.9 Implementation Plan

> This plan becomes issues (see `docs/process.md`, Intake). Do not run it with subagent-driven-development or executing-plans (see `AGENTS.md`).

**Goal:** Ruleset `v1.9` with a spellbook field, spellbook 1 (new blue, red, orange 6), and no "Remove one White 1" in the shop. Bots, record, CLI and RL environments run on it.

**Architecture:** The ruleset names a spellbook; the effect of a coloured chip is looked up through it. Older rulesets keep naming a component per chip and do not change. Blue adds a hidden pick step to the brew phase, as the explosion choice added a step in v1.8. Red needs the whole pot in the place-bonus hook.

**Tech Stack:** Python, pytest (`uv run --with pytest pytest`), existing engine, record, bots, CLI and RL code.
